# Motorbike Rental Mobile Application

## 📌 Overview
A cross-platform mobile application that simplifies the process of searching and renting motorbikes for travelers.

## 👥 Team Size
3 members

## 🎯 My Role
Team Leader & Fullstack Developer

## 🛠 Technologies
- Flutter
- Dart
- Firebase Authentication
- Firebase Firestore
- Firebase Cloud Storage
- Google OAuth

## 🚀 Key Features
- Google OAuth authentication
- Real-time vehicle availability updates
- Instant booking synchronization using Firestore
- Image storage via Cloud Storage

# ⚙️ Installation & Setup Guide

> ⚠️ For security reasons, Firebase configuration files and API keys are NOT included in this repository.  
> You must create your own Firebase project to run the application.
 ## 1️⃣ Create Your Own Firebase Project
1. Go to Firebase Console
2. Create a new project
3. Enable the following services:
   - Authentication → Enable Google Sign-In
   - Firestore Database
   - Cloud Storage
